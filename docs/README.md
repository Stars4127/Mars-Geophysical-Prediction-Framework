# Research Paper

This directory contains the research manuscript accompanying the Martian Geophysical Prediction Framework (MGPF).

## About the Paper

The manuscript documents the project's motivation, methodology, model development, and experimental results. It provides additional technical context for the machine learning approaches used to predict geophysical and surface properties across Mars using planetary remote sensing data.

The paper is included to provide insight into the research process and the technical foundations behind the implementation.

## Publication Status

**Status: Unpublished Research Manuscript**

The PDF is an earlier version of the manuscript and has not been updated or edited recently. As a result, some developments, implementation changes, experimental results, and refinements in the current codebase may not be reflected in the paper.

For the most up-to-date implementation and project details, refer to the source code and documentation in the main repository.
